# Workout Board

CSVまたはTSVに記録した筋力トレーニングを、ローカルで安全に可視化するmacOS向けダッシュボードです。Google Sheetsから書き出したファイルもそのまま取り込めます。

![Bun](https://img.shields.io/badge/runtime-Bun-19231f)
![License](https://img.shields.io/badge/license-MIT-b9f34a)

## 主な機能

- 期間・種目別の総ボリューム、セッション数、セット数、推定1RM
- 日ごとのボリューム、最高重量、推定1RMの成長推移
- 種目別サマリー、セット履歴、最近のメモ
- 不正なシート行を除外し、行番号付きで理由を表示
- CSV／TSV取り込み、取り込みデータの安全なローカル保存
- ライト／ダーク表示、モバイル表示、キーボード操作

推定1RMにはEpley式`重量 × (1 + レップ数 / 30)`を使います。ダンベル重量は入力値をそのまま扱い、両手分への自動換算は行いません。

## 必要な環境

- macOS
- [Bun](https://bun.sh/) 1.3.14以上

Node.jsとnpmは使用しません。依存関係のインストール、スクリプト、テスト、ビルドはすべてBunで実行します。

## データの準備

Google Sheetsを利用する場合は、トレーニング記録があるワークシートを開き、`ファイル` → `ダウンロード` → `カンマ区切り形式（.csv）`から保存します。Google Cloudの設定やWorkout BoardからのGoogleログインは不要です。

CSVとTSVに対応し、ファイルサイズの上限は5MBです。更新後は新しいファイルを再度取り込んでください。将来のバージョンでは、同じデータ処理を利用したGoogle Sheets自動同期を追加する予定です。

形式を確認したい場合は、[サンプルCSV](examples/workouts.csv)を利用できます。

## 起動

```sh
git clone https://github.com/kissy24/workout-board.git
cd workout-board
bun install --frozen-lockfile
bun run dev
```

ブラウザーで`http://127.0.0.1:4173`を開き、画面の案内に従います。

1. `ファイルを取り込む`を選択します。
2. Google Sheetsなどから保存したCSVまたはTSVを選択します。
3. 次回の更新時は、画面右上の取り込みボタンから新しいファイルを選択します。

取り込んだファイルの内容は`~/Library/Application Support/workout-board/imported-workouts.json`へ権限`0600`で保存され、次回起動時に復元されます。外部サーバーへ送信しません。

通常起動ではホットリロードが不要な場合、次を使用できます。

```sh
bun run start
```

ポートを変更する場合は`WORKOUT_BOARD_PORT`へ1024〜65535の値を指定します。

## 取り込みファイル形式

先頭行に次の列名が必要です。列順は入れ替えられます。

| 日付 | 種目 | セット | 重さ(kg) | レップ数 | ボリューム(kg) | メモ |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| 2026-03-04 | ベンチプレス | 1 | 30.0 | 5 | 150.0 |  |

- 日付は`YYYY-MM-DD`、`YYYY/MM/DD`を利用できます。
- ボリュームが空の場合だけ`重さ × レップ数`で補完します。
- メモ以外の不正値を含む行は集計せず、ダッシュボード下部に理由を表示します。
- 列順は自由で、必要な列以外が含まれていても構いません。

## 開発と検証

```sh
bun run check
bun run security
```

`check`はTypeScript、Biome、単体テスト、Bunビルドを順番に実行します。CIではこれらに加えてOSVによる依存関係検査とGitleaksによる秘密情報検査を実行します。パッケージは完全固定し、`bun install --frozen-lockfile`で再現性を確認します。

実データを使わず画面を確認する場合は、組み込みサンプルをメモリ上だけで読み込むデモモードを利用できます。

```sh
WORKOUT_BOARD_DEMO=1 bun run dev
```

デモモードではローカルデータの変更を行いません。

## 取り込みデータの削除

設定画面の「取り込んだデータを削除」から、ローカルに保存したトレーニング記録を削除できます。元のCSV／TSVファイルは削除されません。
